# VERDIX — Ecosistema de Software Abierto

VERDIX es un proyecto de código abierto que construye sistemas operativos, inteligencias artificiales y juegos desde cero.

## VERDIX es un proyecto en construcción

Cada versión trae mejoras en rendimiento, nuevas funcionalidades y mayor estabilidad. Actualmente disponible:

- **VERDIX OS** — Sistema operativo basado en Debian con XFCE
- **Verdix IA** — Asistente inteligente con chat, análisis de imágenes y generación de imágenes
- **Juegos Verdix** — Títulos como Ben 10 Omnitrix Battle para Android
- **Verdix Web** — Sitio web, buscador y herramientas en línea
